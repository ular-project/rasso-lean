## Abstract

Rasso is a relational language for data transformation and combinatorial search: a database states what *is*, and a search problem what *could be*, and which possibility is best. Earlier algebras state search problems by guessing a relation or a function. Rasso instead makes the space of candidate solutions, the function space $`\mathit{Decision}^{\mathit{Data}}`$, an operand, and lifts Codd's operators to act on it: selection keeps candidates, and join combines two search spaces into one. They stay within it, so search problems compose as queries do, one level up, and an order on the candidates states an objective. Rasso's values are finite relations, unrestricted relations, solution sets (sets of candidate relations) and multi-solution sets (sets of candidate databases).
This report introduces the language bottom up and renders each construct in RassoLean, a library in core Lean 4 without Mathlib, which is also an evaluator. It is checked against a reference implementation in Racket, with which it shares no code. Lean proofs show three results. The candidates of $`\mathit{Decision}^{\mathit{Data}}`$ are exactly the graphs of the functions from the data to the decision. A named subalgebra, selection on Boolean function spaces, states exactly the properties that existential second-order logic defines, on structures whose universe is unmixed; by Fagin's theorem, which is cited, these are the NP properties. And $`\Phi`$, which translates a solution set too large to list into one constraint to be searched, keeps its meaning: RassoLean's $`\Phi`$, which takes decisions over finite domains, is proved faithful wherever it gives a result. An appendix lists the algebraic laws of the four algebras, each with its status: Lean proves 128 of them, and for 8 a counterexample, checked in Lean, shows that the law fails. This report is a draft; new versions will follow as the research progresses, and we invite comments.
